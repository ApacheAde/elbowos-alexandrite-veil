# Alexandrite Veil

Full-colour Python 3 neon color-shift territory arcade for [ElbowOS](https://x.com/ElbowOS).

Steer a dual-tone ribbon through the void. Close a loop to drop a veil and trap the rose hunters inside. Alexandrite shifts mint ↔ rose as you play.

Arrows / WASD steer. R reset. ESC quit.

## Play

```
pip install -r requirements.txt
python3 alexandrite_veil.py --play
```

## Record a 9:16 reel

```
python3 alexandrite_veil.py --record
```

Writes a 1080x1920 h264 clip (15s @ 30fps) with title, score, and `x.com/ElbowOS` burned into the frames.
